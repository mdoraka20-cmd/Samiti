Samiti Manager — Setup.exe বানানোর কিট
======================================

কী হবে
 এই কিট দিয়ে এক ক্লিকে "SamitiManager_Setup.exe" বানানো যায় — যেটা Next > Next > Install করলেই
 অ্যাপ ইনস্টল হয়, ডেস্কটপে শর্টকাট আসে, আনইনস্টলারও থাকে। ডাটা কম্পিউটারেই (ইনস্টল ফোল্ডারের data ফোল্ডারে) জমা হয়।
 একবার Setup.exe বানালে সেটি যত খুশি পিসিতে দিতে পারবেন — ইন্টারনেট বা Python লাগবে না।

বানানোর নিয়ম (একবার, একটি Windows পিসিতে; ইন্টারনেট লাগবে)
 ১) ZIP আনজিপ করুন।
 ২) app.py এর উপরের SECRET লাইনের গোপন কী নিজের মতো বদলান (বিতরণের আগে)।
 ৩) MakeInstaller.bat ডাবল ক্লিক করুন। এটি নিজে নিজে: PyInstaller ইনস্টল > অ্যাপ বিল্ড > Inno Setup ইনস্টল > Setup বানায়।
    (Python/Inno Setup না থাকলে winget দিয়ে ইনস্টল করার চেষ্টা করে; হলে উইন্ডো বন্ধ করে আবার চালাতে বলবে।)
 ৪) শেষে Output\SamitiManager_Setup.exe তৈরি হবে।

ইনস্টলারের বৈশিষ্ট্য
 - Program Files এ ইনস্টল হয়, data ফোল্ডার সবার জন্য লেখার অনুমতিসহ তৈরি হয়।
 - নতুন সংস্করণ ওপরে ইনস্টল করলে আগের ডাটা ঠিক থাকে; আনইনস্টল করলেও data ফোল্ডার মুছে না।
 - একবার চালু থাকলে আবার শর্টকাট চাপলে নতুন সার্ভার হয় না, শুধু ব্রাউজার খোলে।

মনে রাখবেন
 - Setup.exe টি সাইন করা নয়, তাই Windows SmartScreen/অ্যান্টিভাইরাস প্রথমবার "Unknown publisher" সতর্কতা দেখাতে পারে ("More info > Run anyway")।
 - প্রথম লগইন admin/admin; ৩০ দিনের ডিফল্ট ট্রায়াল মেয়াদ থাকে — ইনস্টলের পর অ্যাডমিন প্যানেল থেকে মেয়াদ ঠিক করে দিন।
 - অ্যাপ শুধু ওই পিসি থেকেই খোলা যায় (127.0.0.1)। নেটওয়ার্কের অন্য পিসি থেকে চাইলে আলাদা কাজ লাগবে।
