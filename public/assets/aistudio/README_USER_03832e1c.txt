Samiti Manager (সমিতি ম্যানেজমেন্ট) - ব্যবহারের নিয়ম
=====================================================

চালু করা
 - ডেস্কটপ বা Start menu এর "Samiti Manager" শর্টকাটে ডাবল ক্লিক করুন।
 - ব্রাউজারে অ্যাপ খুলবে। একটি কালো উইন্ডো টাস্কবারে ছোট হয়ে থাকবে — ওটাই সার্ভার,
   অ্যাপ ব্যবহারের সময় ওটা বন্ধ করবেন না। কাজ শেষে ওটা বন্ধ করলেই সার্ভার বন্ধ হবে।
 - আবার শর্টকাটে ক্লিক করলে নতুন সার্ভার চালু হয় না, শুধু ব্রাউজার খোলে।

প্রথম লগইন
 - ইউজার: admin   পাসওয়ার্ড: admin
 - সাথে সাথে "পাসওয়ার্ড পরিবর্তন" থেকে পাসওয়ার্ড বদলান।
 - অ্যাডমিন প্যানেল > লাইসেন্স থেকে মেয়াদ ও রিনিউ মেসেজ ঠিক করুন।

ডাটা কোথায় জমা হয়
 - ইনস্টল ফোল্ডারের ভেতর "data" ফোল্ডারে (samiti.db)। সব তথ্য আপনার নিজের কম্পিউটারেই থাকে।
 - সেটিংস > "ব্যাকআপ ডাউনলোড" থেকে নিয়মিত ব্যাকআপ রাখুন (ফাইলটি পেনড্রাইভে/অন্য জায়গায় কপি করে রাখুন)।
 - নতুন সংস্করণ ইনস্টল করলে বা আনইনস্টল করলেও data ফোল্ডারের ডাটা মুছে যায় না।

ব্যাকআপ ফিরিয়ে আনা
 - অ্যাপ বন্ধ করুন > ইনস্টল ফোল্ডারের data\samiti.db এর নাম বদলে samiti_old.db করুন
 - ব্যাকআপ ফাইলটি data ফোল্ডারে রেখে নাম দিন samiti.db > অ্যাপ চালু করুন।
